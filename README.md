# Java Basic Systems

This repository contains a collection of simple Java console applications designed to demonstrate fundamental programming concepts such as loops, conditional structures, mathematical operations, and user input handling using the `Scanner` class.

## 🚀 Projects Overview

The repository is organized into four main modules:

### 1. **Calculadora (Calculator)**
A menu-driven calculator that performs basic arithmetic operations.
* **Features**: Addition, Subtraction, Multiplication, and Division.
* **Safety**: Includes input validation to prevent division by zero.
* **Structure**: Uses a `do-while` loop to allow multiple operations in a single session.

### 2. **Calcular Média (Average Calculator)**
A simple tool to calculate a student's final grade based on four inputs.
* **Inputs**: Student's name and four distinct grades.
* **Logic**: Calculates the arithmetic mean and displays the result to the user.

### 3. **Sistema ATM (ATM Simulator)**
A simulation of an Automated Teller Machine interface with a visual menu.
* **Options**: Users can simulate checking balances (Checking, Savings, or Investment accounts), making transfers, and performing deposits.
* **Interface**: Interactive console menu powered by a `do-while` loop and `switch/if` logic.

### 4. **ForLoop Examples**
A demonstration of iterative structures and basic logic in Java.
* **Increment Loop**: Prints a sequence from 0 to 250 (incrementing by 5).
* **Decrement & Logic**: Iterates backwards and uses the modulus operator (`%`) to filter and print only even numbers.

## 🛠️ Technologies Used
* **Java**: The core programming language.
* **Java Scanner Class**: Utilized for handling real-time user input via the console.
* **NetBeans IDE**: Project structure and configuration files (build.xml, project.xml).
